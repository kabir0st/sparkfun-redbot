\section*{Introduction}
In this lab we programmed an Arduino UNO R4 WiFi, did some basic hardware
prototyping, flew a Ryze Tello drone (manually and from Python), and got a
SparkFun RedBot ground robot to move.

% ---------------- (d) Ground robot ------------------------
\section{Ground robot}
We assembled the RedBot (main board, IR line sensors, wheel encoders, alkaline
battery pack) and worked through the SparkFun tutorials 1--3 (basic motions),
6 (line following) and 7 (encoders)\footnote{\url{https://learn.sparkfun.com/tutorials/experiment-guide-for-redbot-with-shadow-chassis}}.

\pic{redbot.jpeg}{Assembled RedBot.}{fig:redbot}

\paragraph{Comment.} Since we did not have tape to make a line-following track,
we used the Arduino UNO R4 WiFi as the main controller instead. It was connected
to the RedBot through RX/TX (UNO TX $\rightarrow$ RedBot RX, UNO RX $\leftarrow$
RedBot TX, common GND, 9600 baud) and powered by a mobile power bank. The UNO
serves a web page with W/A/S/D controls and forwards each command to the RedBot.
The RedBot drives the motors and sends back the IR line-sensor and encoder
readings, which are shown live on the page. This is how we tested the motions,
the line sensors and the encoders. As a safety measure, the RedBot stops if no
command arrives for 500\,ms.

\pic{redbot_wiring.jpeg}{UNO R4 WiFi (on power bank) connected to the RedBot over RX/TX.}{fig:redbot-wiring}
